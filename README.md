# Rebuilder 3D

**RGB 영상에서 3D 장면을 복원하고 탐색하는 Windows 연구 애플리케이션의 Python 소스 코드**입니다. 원본 프로젝트 **ReconX**(`Project-Recon`)의 `src/reconx` 모듈 64개를 별도 코드 포트폴리오 저장소로 옮겼습니다.

## 구현 내용

- **RGB 영상 복원:** 영상 프레임 선택, PyCOLMAP 기반 SfM 카메라 추정, 상대 깊이 정합, 포즈 품질 검사, TSDF 메시 생성
- **장면 표현:** RGB 색상과 의미 분할 결과를 3D에 융합하고, Gaussian 장면 및 UV 텍스처 메시를 생성·표시
- **데스크톱 앱:** PySide6·PyVista 기반 장면 뷰어, 레이어 전환, 카메라 탐색, 작업 실행 및 결과 확인
- **저장·내보내기:** `.rebuilder` 프로젝트 재열기와 PLY·GLB·OBJ 등 결과 내보내기
- **평가·진단:** 깊이·궤적·메시 비교와 복원 품질 분석을 위한 모듈

## 처리 흐름

`RGB 영상 → 프레임 선택 → SfM → 깊이 정합 → TSDF / Gaussian / 의미 융합 → 뷰어·내보내기`

## 주요 기술

Python, PyCOLMAP, Depth Anything V2, Open3D, gsplat, PySide6, PyVista/VTK, SegFormer

## 저장소 범위

이 저장소에는 **Python 소스 코드만** 보관합니다. 원본 영상·데이터셋, 모델 가중치, 학습 결과, 실행 파일, 가상 환경, 실험 산출물은 포함하지 않습니다. 전체 실행 환경과 검증 자료는 원본 ReconX 프로젝트에 있으며, 이 저장소 단독으로 실행 가능한 배포판은 아닙니다.

RGB 단안 영상만 사용하는 결과는 SfM의 임의 스케일을 따릅니다. 실제 촬영 영상의 복원 범위와 형상 품질은 카메라 등록 및 촬영 커버리지에 따라 달라집니다.
